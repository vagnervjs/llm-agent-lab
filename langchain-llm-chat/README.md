# LangChain LLM Chat

Simple chat interface using LangChain and OpenAI.

## Setup

1. Install dependencies:
```bash
npm install
```

2. Add your OpenAI API key to `.env`:
```
OPENAI_API_KEY=your_api_key_here
```

3. Run the project:
```bash
npx tsx index.ts
```

## What it does

Demonstrates basic LangChain usage with prompt templates and OpenAI GPT-4 for text translation.
